## 🔧 Come far girare un modello *Ollama* locale su un sito web

In pratica devi creare **due livelli**:

| Livello | Cosa fa | Come si può realizzare |
|---------|---------|------------------------|
| **Backend** | Prende la tua richiesta (prompt), la manda a Ollama e restituisce la risposta | Node.js / Express, Python Flask / FastAPI, Go, etc. |
| **Frontend** | Interagisce con l’utente, invia la richiesta al backend e mostra la risposta | Vanilla JS, React, Vue, Svelte, ecc. |

Ollama espone un **API HTTP** (localhost:11434). Il backend è lì per *proxy* la richiesta e gestire eventuali restrizioni CORS, streaming, autenticazione, ecc.  

> **Nota**: Se vuoi vedere la risposta in tempo reale (streaming), usa SSE/WebSocket; altrimenti basta fare una singola chiamata POST.

---

## 1️⃣ Installare Ollama

```bash
# 1. Scarica e installa
curl -fsSL https://ollama.ai/install.sh | sh

# 2. Avvia il servizio (è già in background, ma puoi farlo manualmente)
ollama serve
```

> Ollama ascolta su `http://127.0.0.1:11434`.  
> Se vuoi usare un modello diverso, `ollama pull llama3.1` (o quello che ti serve).

## 2️⃣ Backend – esempio con Node.js + Express

> **Perché Express?**  
> Leggero, facile da impostare e già in grado di gestire JSON, CORS, e streaming.

### 2.1 Preparare l’ambiente

```bash
mkdir ollama-web
cd ollama-web
npm init -y
npm i express cors node-fetch@2
```

> *node-fetch v2* è la versione “classic” compatibile con `require()`.  
> Se usi ES modules (`import`), installa `node-fetch@3`.

### 2.2 Codice del server

```js
// server.js
const express = require('express');
const cors = require('cors');
const fetch = require('node-fetch');

const app = express();
const PORT = 3000;

// Permetti richieste da qualsiasi origine (solo per sviluppo)
// In produzione dovresti restringere l’origin
app.use(cors());
app.use(express.json());

// Endpoint che chiama Ollama
app.post('/ask', async (req, res) => {
  const { prompt } = req.body;

  if (!prompt) {
    return res.status(400).json({ error: 'Missing prompt' });
  }

  try {
    // Richiesta a Ollama
    const ollamaRes = await fetch('http://127.0.0.1:11434/api/generate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: 'llama3',          // oppure llama3.1, mistral, ecc.
        prompt,
        stream: false,           // cambia in true per streaming
      }),
    });

    if (!ollamaRes.ok) {
      const errText = await ollamaRes.text();
      return res.status(ollamaRes.status).json({ error: errText });
    }

    const data = await ollamaRes.json();
    res.json({ response: data.response }); // data.response è il testo generato
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: 'Errore interno' });
  }
});

app.listen(PORT, () => {
  console.log(`🚀 Backend in ascolto su http://localhost:${PORT}`);
});
```

## 🎯 Obiettivo  
Mettere a disposizione **un’interfaccia web** (frontend) che invii un *prompt* a **Ollama** (model run locally) e mostri la risposta in tempo reale.

L’architettura tipica è:

```
+----------------+      HTTP POST      +------------------+      HTTP GET      +-----------------+
|  Frontend (web)|  →  /api/ask       |  Backend (proxy) |  →  Ollama API    |  Ollama (LLM)   |
+----------------+                      +------------------+                    +-----------------+
```

> **Perché un proxy?**  
> 1. Evita problemi CORS (il browser non può chiamare direttamente `127.0.0.1:11434` dal dominio del tuo sito).  
> 2. Permette di aggiungere logica di sicurezza, autenticazione, throttling, streaming, ecc.  
> 3. Può essere distribuito su qualsiasi server (Docker, VPS, etc.) senza cambiare il codice del frontend.

## 2️⃣ Backend – esempio con Node.js + Express

> ⚙️ **Perché Express?**  
> Leggero, supporta CORS, streaming e si integra facilmente con la CLI di Ollama.

### 2.1 Setup del progetto

```bash
mkdir ollama-web
cd ollama-web
npm init -y
npm i express cors node-fetch@2
```

> *node-fetch@2* è compatibile con `require()`; se vuoi usare `import`, installa la versione 3.

### 2.2 Codice del server (`server.js`)

```js
// server.js
const express = require('express');
const cors = require('cors');
const fetch = require('node-fetch');

const app = express();
const PORT = 3000;

// 1. CORS – in produzione restringi l’origin
app.use(cors({ origin: 'https://tuodominio.com' }));
app.use(express.json());           // body-parser

/**
 * POST /ask
 * body: { prompt: string }
 */
app.post('/ask', async (req, res) => {
  const { prompt } = req.body;

  if (!prompt) return res.status(400).json({ error: 'prompt required' });

  try {
    // 2. Richiesta a Ollama
    const ollamaRes = await fetch('http://127.0.0.1:11434/api/generate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: 'llama3.1',          // <-- cambiare se vuoi un altro modello
        prompt,
        stream: false,              // true = streaming (vedi sotto)
      }),
    });

    if (!ollamaRes.ok) {
      const err = await ollamaRes.text();
      return res.status(ollamaRes.status).json({ error: err });
    }

    const data = await ollamaRes.json();   // data.response contiene il testo generato
    res.json({ response: data.response });

  } catch (err) {
    console.error(err);
    res.status(500).json({ error: 'Errore interno' });
  }
});

app.listen(PORT, () => console.log(`🟢 Backend listening on http://localhost:${PORT}`));
```

#### Streaming (opzionale)

Se vuoi che la risposta arrivi “in tempo reale” (ad es. per chat), imposta `stream: true`.  
Quindi leggi lo *stream* dalla risposta di Ollama e invialo al client con SSE (`EventSource`) o WebSocket.

```js
// Esempio di SSE
app.get('/stream', async (req, res) => {
  const { prompt } = req.query;
  // ... chiedi a Ollama con stream:true
  // invia chunk con `res.write(`data: ${chunk}\n\n`);
});
```

## 3️⃣ Frontend – semplice demo con Vanilla JS

### 3.1 HTML (`index.html`)

```html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <title>Ollama Demo</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 2rem; }
    textarea { width: 100%; height: 80px; }
    #output { margin-top: 1rem; padding: 1rem; border: 1px solid #ccc; white-space: pre-wrap; }
  </style>
</head>
<body>
  <h1>Chat con Ollama (locale)</h1>
  <textarea id="prompt" placeholder="Scrivi qui..."></textarea><br>
  <button id="send">Invia</button>
  <div id="output"></div>

  <script src="app.js"></script>
</body>
</html>
```

### 3.2 JavaScript (`app.js`)

```js
const btn = document.getElementById('send');
const promptEl = document.getElementById('prompt');
const out = document.getElementById('output');

btn.addEventListener('click', async () => {
  const prompt = promptEl.value.trim();
  if (!prompt) { alert('Inserisci un prompt'); return; }

  out.textContent = '⏳ ...';
  try {
    const res = await fetch('/ask', {   // 1. Chiamata al backend
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ prompt })
    });

    if (!res.ok) {
      const err = await res.text();
      throw new Error(err);
    }

    const data = await res.json();
    out.textContent = data.response;   // 2. Mostra la risposta
  } catch (e) {
    out.textContent = '❌ ' + e.message;
  }
});
```

> Se hai abilitato **streaming** con SSE, cambia il `fetch` con:

```js
const eventSource = new EventSource(`/stream?prompt=${encodeURIComponent(prompt)}`);
eventSource.onmessage = e => out.textContent += e.data;
```

## 4️⃣ Distribuzione

1. **Development**  
   ```bash
   node server.js   # backend
   # apri index.html nel browser (o usa http-server)
   ```

2. **Production**  
   - Collega il backend a un reverse‑proxy (Nginx, Caddy, Traefik).  
   - Serve `index.html` statico dalla stessa macchina (o da un CDN).  
   - Se vuoi portare l’intera app su Docker:

```dockerfile
# Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
EXPOSE 3000
CMD ["node","server.js"]
```

```bash
docker build -t ollama-web .
docker run -p 80:3000 ollama-web
```

3. **CORS & HTTPS**  
   - In produzione usa HTTPS (Let’s Encrypt, Cloudflare).  
   - Configura `cors({origin: 'https://tuodominio.com'})`.
